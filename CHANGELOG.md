# Changelog

## 0.1.0 (unreleased): testers' preview

The first build for other people's devices (macOS, Android, the keeper on Linux). Written up for testers in R1-12.

- From this version on, wire protocols, signing domains and on-disk files are kept compatible: see
  [docs/notes/formats.md](docs/notes/formats.md) and "Changing a format" in [CONTRIBUTING.md](CONTRIBUTING.md).
- On-disk layout 2: data from earlier development builds is upgraded on first start (a copy of the small files is kept
  under `backups/`).
- Settings → About shows the version, the build and where the source is; the third-party licence notices ship with
  the app and the keeper (`shoebox-keeper licences`), generated by `scripts/licences.py`.
- Security alerts (a new admin device, a replaced recovery phrase) reach you with the app closed: a notification on
  Android and on the desktop, and `shoebox-keeper status` / `alerts` on the keeper.
- The app and the keeper tell you when a newer version is out (Settings → About → Check for new versions; the keeper's
  `status`). Nothing is installed automatically.
- Phones can add photos by hand (＋ in the Library): from any album through the system photo picker, or from files.
- Devices → Storage shows how much of the library each device holds (originals, previews).
