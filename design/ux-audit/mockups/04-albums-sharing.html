4 · Albums & sharing

Sharing becomes a property of an album, not a separate place. An album has one Share button that offers three clear choices, and a selection's share sheet puts the system share sheet first. Covers come from the newest photo when none is set. Fixes F2, F5, F6, F7, F11, F12.

Invite flow: remote first, QR for in person

Today an invitation is a QR code plus a 300-character code in a text box. The redesign makes a link-like invitation that you send through the system share sheet, which covers most cases because friends are usually somewhere else. QR is the second choice, for when you are together. The long code stays behind "Copy code" for edge cases. The person joining taps the link and sees the album name and who invited them.

What merges

  1. Albums.svelte and Shared.svelte become one list. "Shared" is a filter chip on desktop and a pill on each card.
  2. SharedAlbum.svelte keeps its Activity and People tabs, but uses the main Viewer.svelte for photos.
  3. Album covers: use the stored cover if one is set, otherwise the newest photo. A "Set as cover" item goes in the viewer's ⋯ menu.
  4. Rename comes to the phone (in ⋯).
  5. The web link stays a power feature. With no service set up, the row says "Needs a link service, set up once" and the setup asks one question at a time.
