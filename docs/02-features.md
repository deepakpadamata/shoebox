# 02 · Feature set

Features are grouped into areas (F1–F8) and tagged by phase:

- **MVP** — the base feature set; the smallest thing that's genuinely useful day to day.
- **v1.x** — next, once MVP is solid.
- **v2** — hosted/optional services (web viewer, gateway, cloud backup).
- **Later** — good ideas, deliberately deferred.

Each mockup screen lists the IDs it covers (see `design/README.md`).

---

## F1 · Identity & onboarding

| ID | Feature | Phase | Notes |
|---|---|---|---|
| F1.1 | Generate device identity on first launch | MVP | iroh endpoint secret key, stored in OS keychain/keystore. |
| F1.2 | Create a new library *or* join an existing one | MVP | First device creates the library; others join by pairing (F4). |
| F1.3 | Display name + avatar for this person | MVP | Shown to people you share albums with. Local profile, gossiped to peers. |
| F1.4 | Recovery kit | MVP | Exportable recovery phrase/file holding the library root key (signs the device list), so losing all devices ≠ losing the library's identity. Skippable in onboarding; persistent banner until saved. |
| F1.5 | Choose import source during onboarding | MVP | Camera roll (mobile) / folders (desktop). Can skip. |

## F4 · Devices & sync

| ID | Feature | Phase | Notes |
|---|---|---|---|
| F4.1 | Pair a new device via QR / ticket | MVP | Existing device shows QR containing an iroh ticket; new device scans; both confirm a short code (prevents MITM / wrong-device pairing). |
| F4.2 | Device list with status | MVP | Online/offline, last seen, direct vs relayed connection, storage used. |
| F4.3 | Per-device storage role | MVP | **Keeper** (keeps all originals) · **Phone** (originals of own captures until safely backed up, previews for rest) · **Viewer** (thumbnails/previews only). |
| F4.4 | Sync activity / queue | MVP | What's uploading, from where, paused-why (battery, metered network, backgrounded). Mobile background sync is best-effort; show "open the app to finish syncing" honestly. |
| F4.5 | Remove / revoke a device | MVP | Revocation signed by the library root key and synced in the device list. |
| F4.6 | Headless keeper (CLI/daemon for NAS, Raspberry Pi, VPS) | MVP | Same protocol, no UI. The always-on backstop that makes P2P sync reliable. |
| F4.7 | LAN-first discovery (mDNS) | MVP | iroh local discovery so devices at home sync without the internet. |
