# Fixtures

Test inputs for import, sync and benchmark work (M0-08). Everything here is **generated by this
repository's own code** (`xtask`), so there is no third-party content and no attribution to carry.

## Synthetic corpus (`cargo xtask fixtures`)

```bash
cargo xtask fixtures --preset small    #    200 photos  (files)
cargo xtask fixtures --preset medium   # 10,000 photos  (files, ~42 MB, < 2 s)
cargo xtask fixtures --preset large    # 100,000 entries (manifest only, for store benchmarks)
```

Options: `--out DIR` (default `fixtures-out/<preset>`, git-ignored), `--seed N` (default 1; same seed → same
corpus byte for byte), `--metadata-only` / `--with-files` to override a preset's default.

What it produces:

- `photos/<year>/<month>/IMG_<n>.jpg` — tiny JPEGs with real EXIF: camera make/model/lens, `DateTimeOriginal`
  spread over ~12 years, pixel dimensions, and GPS on ~40% of photos.
- ~5% **exact duplicates** (byte-identical copies of an earlier photo under a different name).
- `manifest.jsonl` — one JSON row per photo: `path`, `blake3`, `size`, `taken_at` (unix secs), camera fields,
  `gps`, `width`, `height`, `duplicate_of`. In metadata-only mode there are no image bytes, so `size` is 0 and
  `blake3` is a stable stand-in derived from the content seed (duplicates still share a hash).

## Checked-in samples (`fixtures/samples/`, regenerate with `cargo xtask samples`)

Total ≈ 0.3 MB (limit: 20 MB). All files were generated from scratch by `xtask` (video via `ffmpeg`, HEIC via
`heif-enc`), so they are released under **CC0-1.0** (or, at your option, the repository's Apache-2.0 / MIT licenses).

| File | Format | Source | License | Notes |
|---|---|---|---|---|
| `photo-gps.jpg` | JPEG 640×480 | `xtask` (`jpeg-encoder`) | CC0-1.0 | EXIF with camera, lens, capture time and GPS (Paris) |
| `photo.heic` | HEIC 640×480 | `heif-enc` from `photo-gps.jpg` | CC0-1.0 | EXIF carried over by libheif |
| `IMG_0001.jpg` + `IMG_0001.dng` | RAW+JPEG pair | `xtask` | CC0-1.0 | Same stem, same capture time. **The `.dng` is a synthetic stand-in**: a structurally valid TIFF/DNG (16-bit RGGB CFA) that exercises pairing and extension handling, but is *not* decodable by RAW decoders (macOS ImageIO rejects it). Replace it with a real, permissively licensed DNG before testing RAW decoding (M1-04 / M3). |
| `screenshot.png` | PNG 390×844 | `xtask` (`png`) | CC0-1.0 | Phone-screenshot-like UI (no EXIF), as a screenshot would be |
| `clip.mp4` | H.264 MP4, 2 s | `ffmpeg` `testsrc2` | CC0-1.0 | `creation_time` metadata |
| `clip.mov` | H.264 MOV, 2 s | `ffmpeg` `testsrc2` | CC0-1.0 | `creation_time` + QuickTime `location` (Paris) |

`HEIC` and video generation need `heif-enc` and `ffmpeg` on `PATH`; without them `cargo xtask samples` skips those files
with a warning and the corresponding tests are unaffected.
