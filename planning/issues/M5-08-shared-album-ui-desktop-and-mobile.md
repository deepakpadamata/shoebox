# M5-08 · Shared album UI (desktop and mobile)

## Why

Mockups 4a–4e on both form factors, plus the Shared tab.

## Scope

- Albums tab: shared section with unread dots. Shared tab: cross-album activity feed.
- Album view: feed grouped by contribution, members bar, '+ Add photos'.
- Invite sheet (role segment, QR, link, expiry). Accept-invite screen (storage cost, join-as, keep originals on keeper).
- Location prompt sheet (4e). Member management screens.

## Acceptance criteria

- [ ] Every 4a–4e mockup state is implemented on desktop and mobile.
- [ ] A two-household test (4 devices) runs through create → invite → add → remove member without help.
