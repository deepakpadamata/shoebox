# M7-01 · User and self-hosting documentation

## Why

Users need to understand roles, keepers and recovery without us.

## Scope

- User guide: concepts (devices are the account, roles, copy count), onboarding, sharing, recovery.
- Keeper guide: Pi/NAS/VPS install, service, storage sizing, upgrades.
- Relay guide: using a custom iroh relay.

- [ ] A beta tester sets up a keeper from the guide alone.
